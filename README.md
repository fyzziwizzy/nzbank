# nzbank

A public mono repo for New Zealand financial services.

This repository hosts studio capabilities: shared building blocks, reference implementations, and reusable assets that teams can pick up and apply to financial services work in the New Zealand market.

## What lives here

| Area | Purpose |
| :--- | :--- |
| Capabilities | Self contained studio capabilities, each in its own folder |
| Reference | Worked examples and reference implementations |
| Shared | Common utilities, schemas, and assets used across capabilities |
| Docs | Guidance, patterns, and background material |
